06 Snapshot contract

Report ID: {{.ID}}. All data was read in one database snapshot, then persisted as an immutable report record. Fetching this ID renders the saved snapshot using its stored HTML; no agents, tests or judges are invoked.

Accounting: {{.Accounting}}. Cached tokens are included; reasoning is not added twice. A model field is the last value reported for its session, not proof that only one model was used.

History includes executions created within the UTC interval [from, to). An explicitly selected execution is shown even outside that history window. No scenario or assessment identity is inferred from factory names or agent text. Source configuration and environment secrets are excluded.

Control-plane execution review · offline HTML · measurements and assessments are separate
